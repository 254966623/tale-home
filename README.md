随后，在夜色忧郁的月光下，窗帘摆动如水草，他长长叹了口气，被磕破的眼窝伤痕下有光盈盈。
“你哭了？”
陈信不可置信地看着眼前这个二十三岁的小伙子。
“我失业了。”
叶休颓然道。
“放心吧，你垫的钱我会还你的。”
“.……”
陈信不知道怎么回答。
讲实话，垫钱也纯粹是他觉得这哥们受伤，自己也算有点责任。因为据苏玉说，灾厄虽然会袭击普通人，但更多的目标是神眷者。
“没事没事。”
他之后这样安慰自己和叶休。
“还年轻，钱总能再赚。”
因为手头拮据，所以在叶休醒来后，第一时间转了四人间，所以病房里也有其他病人。
听到两人的谈话，隔壁床大妈插了一嘴。
“没钱可以让医生帮忙垫呀小伙子，唉，真的是。我看人家电视上医生都说了，遇到没钱的病人会帮忙垫钱这样子的。”
“你们现在的年轻人，太不会过日子了。我告诉你们，这些医院的医生护士个个都有钱得很，退休金都几万几万发，房子在北京深圳都几套的，要不然你以为我们开这么贵的检查，还有红包什么的，钱都去哪了……就该让他们给我们垫着……你们是不知道哦，我一朋友的叔父在相娅医院当内科主任，你猜怎么？嘿嘿，光是开住院证，都一个月几十万……”
大妈见其他两床位的病人凑过来听，说得更起劲起来，节奏抑扬有致，音调婉转悠扬。 
“咳咳。”
陈信咳嗽了下。
门口，脱去一身白大褂的许知秋俏生生站着，看不出表情。
“我和财务处那边打过招呼了，这个属于灾厄事件报销范围，争取早点给你报销下来。”
得知可以报销的第一时间，陈信就腆着脸挂了个许知秋的复诊号，让帮忙催下报销流程提交。
不得不说，无论哪行哪业，大部分年轻人都更有同理心。
听完事情因果，许知秋也是当场点了头。
顺便给陈信重新做了几套心理评估。
大妈牛皮也不吹了，一脸八卦地凑上来。
“小伙子，你对象？长挺标致啊，哎这身高，小姑娘得有一米七吧。”
“不是不是……”
陈信连连摆手。
“不是？唉，现在的小伙子们都怎么回事，刚好我侄子还没结婚，二十六岁，刚在警察局上班还没结婚，怎么样，小姑娘，你多大了啊，要不要加个联系方式，我介绍下你们认识。”
许知秋似乎对类似场景倒是轻车熟路。
“不了阿姨，我快四十，结婚了，有小孩。”
“哎呀，真的假的，多可惜，你可别骗姨啊！你这看着可不像三十，怎么保养的，教教姨，我最近老觉得自己皱纹越来越多了，美容院那小姑娘老给我推荐项目，我也不清楚，你给姨说说怎么选好……哎呦，这皮肤，和十八岁小姑娘似的……”
大妈拿手摩挲起许知秋的手腕。
“……”
许知秋像是有话要说。
陈信连忙拉开大妈：“唉，阿姨，我和你说，美容院那些什么的都骗人的，你找你那内科主任亲戚给介绍个皮肤科医生，做个什么嫩肤或者除皱，就阿姨，不对，姐你这底子，保证比那什么刘亦菲还漂亮！”
虽然刘亦菲是老一辈男性的国民女神，但拿这个夸也准没错。
“我们还有点事要聊，晚点回来哈。”
果然大妈听到这话，脸笑开得像烂掉的橘子灿烂。
“小伙子真会说话。”
她拿回手，摸了摸自己的脸。
“唉，那小伙子你有对象没……”
她笑得眯起的眼睛睁开，要看那讨喜的小伙，只看到病床上的叶休瞪大了眼，盯着门口的方向。
那方向，自然是陈信在大妈松开许知秋的手瞬间，拉着她离开的方向。

“嗯嗯。没事没事，我谢谢你才对。”
陈信尴尬地摸鼻子。
“那啥，我今天看自己病历，评分是61，这事……也谢谢你了。”
他指的自然是之前自己差点成小白鼠的事。
许知秋帮着主张他参与感染试炼的权利。
事后把病历的评分也改了。
“没事。你的精神评估本来就是正常。只是正常的更新。”
许知秋扶了扶镜框。
“你……朋友的医保报销材料记得准备下，财务处说明天给你提交下申请。”
陈信点头：“行，主要是证明材料？不过那个鼠人的尸体都成焦糊了……特管局那边的案件登记可以么？”
“可以，记得要结案的盖章。”
陈信庆幸自己在紫电女战士离开后马上找了苏玉，后边苏玉带着特管局人员来了现场做了登记，至于结案没有，自己还得问下。
陈信看了眼时间，八点二十七，回去特管大学那边做个地铁估计也就一个多小时。
“那个，许医生你下班了吧，有时间么，没吃饭的话我请你吃个晚饭……额，夜宵？”
许知秋脸色犹豫了下，捂了捂肚子，随后还是点了点头。
“许医生喜欢吃些什么？”
“清淡点的就行。”
“我看看啊……”
陈信也没什么请人吃饭的经验，只好掏出手机在丑团上查看附近推荐。
额，附近，按距离。
薛记螺蛳粉……
清淡的，应该是粤菜或者是砂锅粥之类吧。

二人站在医院门口，刚好是医院上下班高峰期，可能不单是他和异性之间独处显得尴尬，许知秋大概也会因为同事上下班看见有些不方便吧？

谢谢你，蜜雪冰城，无处不在，只要有一个空隙就能插入的、顽强的蜜雪冰城！
从医院旁的人行道过去，大约只有几百米，也能稍微避开些许知秋的同事之类的，
嗯，虽然不知道自己为什么想避开对方同事。
她大概会想避开自己同事？

许知秋似乎是有些走神。
奇怪的是，也没在玩手机。

八点并不算下班高峰点，但医院加上商业街的人流量可能还是比较嘈杂。

“你爱我呀我爱你，蜜雪冰城甜蜜蜜~”
